# 5x5 dev notes (2026-10-16)

Covers commit 34d39e8 "AI opponents, menu and HUD redesign" (branch ai-opponent, merged to main).
The code namespace is still `ThreeMusketeers`; the game is called 5x5. Renaming the namespace is on the to-do list.

## Screen flow (MainMenuController.cs)
- Home: logo (or title text), Play, Quit (hidden on phones unless "Show Quit On Mobile"), settings gear, store icon.
- Settings: music and sound-effect sliders. Opened from Home, the in-game gear, or Pause.
- Store: placeholder item only. The Home store icon is locked until "Store Unlocked" is on or SetStoreUnlocked(true) is called.
- Play overlay: two rows, Theme and Players, plus Start and Back. After a match the same overlay is the game-over screen
  (result headline, Rematch, Main Menu, and an X that closes it to show the final board).
- Select Theme and Select Players work on drafts: tapping highlights, Confirm saves and goes back, Back discards.
- Pause (HUD Pause button): Resume, New Game, Settings, Quit to Main Menu. Both New Game and Quit confirm first if a match is in progress.
- Any open screen freezes the match, including the AI turn (Time.timeScale = 0). It is restored to 1 when the screens close.
- Saved choices (PlayerPrefs): SelectedThemeId, PlayMode, HumanSide, OpponentId.
- Hierarchy rule: the GameUIController object (UIRoot) must sit above the MainMenu object under the Canvas, so menus draw over the HUD.

## Look and branding
- UIStyle.cs / UIStyle asset (Assets/Scripts/UI/UIStyle.asset): three text roles (Title, Button, Body), palette, sizes, icon sprites,
  a Default Button sprite, and one art slot per button (Button Art). Empty slot falls back to Default Button, then a flat color.
- Per-theme overrides: ThemeDefinition.uiOverrides (fonts, primary button color, Home background, logo).
- UIBuilder.cs builds every element from code and restyles live when the theme changes. SafeAreaFitter.cs keeps content out of notches.
- Fonts use TextMeshPro. TMP Essentials are imported (Assets/TextMesh Pro). Your old menu font still needs converting to a TMP font asset.

## Computer opponents
- OpponentDefinition.cs (Assets/Scripts/AI): Display Name (empty shows "Computer"), Tier (Easy to Expert), hand-written Style Adjectives,
  and the four AI levers. Four starter assets live in Assets/Opponents (menu: 5x5 > Create Default Opponents).
- The assets must be listed in MainMenuController > Available Opponents. If the list is empty the menu uses nameless built-in ones
  and logs a warning. The starter adjectives are placeholders written by hand; nothing maps levers to adjectives in code.
- The four levers (AIProfile.cs): search depth, top-N move randomness, blunder chance with a severity cap, opponent model
  (Optimal, Greedy or Random). MinimaxAgent.cs searches with alpha-beta pruning on a copy of the board.
- Seats: GameManager.SetSeats(AIProfile offense, AIProfile defense) then StartNewGame(); null means a human.
- GameManager raises GameEnded(result, winText), exposes MatchInProgress and AbandonMatch().
- Measured on a desktop (phones not measured): depth 7 about 36 to 81 ms mid-game, depth 9 about 0.55 s, depth 10 about 3 s.
  Expert is depth 8. In equal-strength play Offense wins about 73 to 75 percent.

## Gotchas
- Changes made to scene objects during Play mode are discarded when you stop. Edit Available Opponents with Play stopped, then save the scene.
- The Unity Performance Testing package writes Assets/Resources/PerformanceTestRun* during builds. Those paths are in .gitignore.
- Store Icon Anchor and the other scene values are saved in mainScene.unity, so changing a default in code does not change an existing scene.
